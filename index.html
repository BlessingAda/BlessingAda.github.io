Payment Reconciliation & AR Aging Tool

Personal project · 2026 · Python, SQL · Built with Claude Code

  • Python
  • SQL
  • Accounts Receivable
  • Automation

As a Revenue Analyst at Kyosk Digital, I checked every day that shop payments matched the right invoices and followed up on overdue accounts. I built this tool to show how that work can be automated, using made-up sample data.

94%of payments matched automatically
5aging buckets, from current to 90+ days
6automated tests, all passing
  • Matches payments to invoices by invoice number, or by shop name and exact amount when the number is missing.
  • Labels each invoice as paid, part-paid or unpaid.
  • Builds an aging report and SQL queries that rank which shops to call first.
  • Flags unmatched payments with a reason, so a person only reviews the problems.
